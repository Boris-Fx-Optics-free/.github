## 🧠 Overview

Boris FX Optics is a collection of optical and photographic effects for Photoshop and Lightroom: light rays, lens flares, film stock, diffusion filters, colour grades and gobo patterns, each with physical-style parameters.

On a Windows machine it runs as a plug-in suite that loads inside Adobe Photoshop CC 2019 or newer, Adobe Lightroom Classic. Typical use is optical and film effects work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🔆 Light Rays and Flares | Anamorphic streaks, lens flares and volumetric light with position controls. |
| 🎞️ Film Stocks | Colour negative and reversal emulations with grain and halation. |
| 🌫️ Diffusion and Mist | Pro-Mist and black-mist style filters that bloom highlights without losing contrast. |
| 🎨 Colour Grades | LUT-based grades and split toning presets. |
| 🔭 Gobos and Patterns | Projected light patterns through shapes and blinds. |
| 🧩 Layer Compositing | Each preset appears as a layer group, editable with masks and blend modes. |
| 🎚️ Physical Parameters | Aperture, blade count and focal length shape the flare instead of fixed images. |
